# The Abu Tricka Science Hub

Year 2 current release for SHS students.

## Files
- `index.html` — complete static application
- `data.js` — Year 2 lesson database, topic quizzes and subject mock-exam data
- `manifest.webmanifest` — PWA manifest
- `sw.js` — service worker/offline cache
- `assets/` — supplied creator/school branding image and preserved portrait crop

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from branch → choose the main branch and `/root`.
4. Open the generated GitHub Pages URL.

No server or paid API is required for the core platform.

## Content note
The learning explanations are original instructional writing organised around the Year 2 structure. They are not copied wholesale from learner textbooks.
